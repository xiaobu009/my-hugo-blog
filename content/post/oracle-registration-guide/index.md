## 第一步：注册前的准备

Oracle 的风控逻辑简单说就是：**你提供的身份信息（邮箱、信用卡、手机、地址）电脑环境及上网环境必须互相对得上**。准备工作做的越扎实，被判定为"可疑"的概率就越低。因此成功注册的前提，不是一上来就打开页面，开始注册步骤，而是先把下面几件东西准备好。

### 1、电脑环境

先说电脑环境，这个地方很容易被忽略，不管你使用的是Windows 系统还是MacOS系统，所在**国家**，**时区**，**显示语言**要保持一致。比如所在的地区是中国，以中国人身份注册甲骨文云，那国家这里就要选中国，时区选北京，显示语言选简体中文。如果是MacOS系统，还要注意将苹果ID换成国内的Apple ID。当然注册链接也要选择相同区域，比如大陆地区注册链接是：https://www.oracle.com/cn/cloud/free

### 2、浏览器环境

注册时无论使用微软的Edge浏览器，谷歌浏览器，苹果的Safari浏览器，都可以，但要保持浏览器够干净，不要开一堆的插件，不要登录一堆复杂的账号。如果是Windows系统开无痕模式，如果是MacOS系统，使用苹果原生的Safari浏览器就行，我是在Mac Mini下成功注册，使用的是Safri浏览器。建议在苹果系统下注册甲骨文云账号，成功率比Windows下注册高。

### 3、网络环境

注册过程中**使用真实的家庭宽带或手机热点**，不要开科学上网，避免在不同的网络间频繁切换。不是能否访问 Oracle 官网的问题，而是注册审核阶段，**用代理/VPN 掩盖真实地理位置，会被风控判定为"刻意遮挡身份信息"，直接拉高被拒概率**。所以一定要使用本地家庭网络或本地运营商的移动网络注册。我注册时使用的就是家庭Wifi网络。

### 4、邮箱

如果你是中国大陆用户，建议使用不科学上网就能访问的邮箱，比如微软的 **Outlook** 邮箱。国内邮箱（QQ、163）不是绝对不能用，只是社区反馈成功率明显偏低，这个地方反馈不一小伙伴自己斟酌着定，当然不是非用Outlook邮箱不可，其他常用邮箱也行，只要不开代理的情况下能正常访问就行。但一定不要一上来就用Gmail，Yahoo，Mail 这种国际邮箱，原因很简单，因为注册过程中会收到甲骨文官方的验证邮件，如果用的是Gmail这类国际邮箱，需要科学上网才能收邮件，而一旦在注册过程中切换网络环境，很容易被甲骨文判定为刻意隐藏身份信息。另外提醒一下，不要使用最近注册过甲骨文云的邮箱。

### 5、支付方式

这是整个流程中最关键的一环，有几个地方要重点关注：

- 大陆地区的用户要使用**大陆发卡行发行的**，**支持国际支付的信用卡**，目前主要是Visa卡和Master卡。
- 必须是**真实的** Visa 或 Mastercard 信用卡。**预付卡、虚拟卡基本会直接被拒**
- **使用本人的信用卡**，**银行卡的持卡人姓名、账单地址，必须与注册时填写的姓名、地址完全一致**，哪怕是大小写或缩写不一致都可能触发风控，因为这一步本身就是在验证用户的身份，个人资料与支付工具信息越统一注册过程就越顺利。
- 国内网友推荐最多的是招商银行的外币信用卡，但这不是唯一的选择，主流银行的外币信用卡，都可尝试注册，但不建议使用带银联标志的外币卡，这次我用的是工商银行全币种环球旅行卡，同样通过了。

> **重要提醒：注册成功后不要注销这张卡。** 有用户反馈 Oracle 在账号使用过程中可能会对同一张卡进行二次验证扣款，注销了卡会导致账号被冻结。

### 6、个人信息一致性

姓名、手机号、邮箱、地址、信用卡信息，这五项尽量保是一个人的。用中国身份注册，就用中国手机号、中国地址，不要东拼西凑（比如用美国地址配中国手机号），**信息不匹配是被拒最常见的原因之一**。

另外要注意：**邮箱、手机号、信用卡这三项，Oracle 规定每人只能注册一个免费账号，重复使用同一项去注册第二个账号，大概率会被判定为重复注册而拒绝。**

### 7、手机号

这里不用太过纠结，手机号不是最主要的门槛，你本人真实在用的国内手机号或其他国内号码都可以，不要用注册过甲骨文云的号码。**不要用虚拟号、临时号**，这类号码很容易被风控系统标记为不可信。

## 第二步：注册流程及关键节点

准备工作做完了，接下来进入实际注册申请流程。


>**注意不同区域申请链接不同：**<br>
大陆：[https://www.oracle.com/cn/cloud/free/ ](https://www.oracle.com/cn/cloud/free/ )<br>
美国：[https://www.oracle.com/cloud/free/](ttps://www.oracle.com/cloud/free/)<br>
日本：[https://www.oracle.com/jp/cloud/free/](https://www.oracle.com/jp/cloud/free/)<br>
韩国：[https://www.oracle.com/kr/cloud/free/](https://www.oracle.com/kr/cloud/free/)<br>
新加坡：[https://www.oracle.com/asean/cloud/free/](https://www.oracle.com/asean/cloud/free/)<br>

打开 [甲骨文云中国区注册链接](https://www.oracle.com/cn/cloud/free)，按以下顺序填写：

1. **账户信息：**国家、名字，姓氏、邮箱，**全部按照真实信息填写**

2. **邮箱验证：**登录邮箱管理后台，打开验证邮件进行验证

3. **补全账户信息：**

   邮箱验证后会返回到账户信息这个页面，继续补齐信息，备用姓名这里输入全名的汉语拼音，大小写与上面姓名相同。然后输入密码，密码八个字符以上，至少要包含一个大、小写字母，一个数字和一个特殊字符。这个密码就是以后登Oracle后台的密码，登录用户名就是之前注册的邮箱。客户类型选 “个人”。

4. **Cloud 账户名称**：

   填写 Cloud Account Name（账号名，每个名称只能申请一次，建议用英文+数字组合，全局唯一），这个账户名称以后登录甲骨文云的时候到要填写，记下来不要忘记了。

5. **选择 Home Region**（主区域）：

   甲骨文在世界多地区提供云服务，这里选的主区域就是你今后要创建vps实例的区域，**且主区域一旦选定，事后无法更改，慎重选**。并且会直接影响以后抢 ARM 实例的难度（不同区域可用的区数量、资源紧张程度不一样）。

   如果你想网络延迟更低网速更快，就选东京，大版，新加坡，韩国，这几个离中国大陆近一些的国家，但东京和首尔这两个国家太过热门，Oracle也提醒很难申请的到，选另外两个，大版或新加坡。

   如果你更在意区域，想注册并使用Claude，ChatGPT，Grok等有地域限制的应用，那就直接选美区作为主区域，比如美国西部（Phonenix）凤凰城，美国东部（Ashburn）阿什本，他们都拥有相对较多的可选区数量，这也是给自己以后抢Arm实例留更多余地。凤凰城靠近西海岸，离中国更近网络延时更小，阿什本在美国东部，离中国更远，延迟更高，虽距离上确有差异，但网络质量上完全不用担心。这次成功注册我选的是凤凰城，他有三个可供切换的区域。

6. **地址信息**：地址信息、城市、省市信息、邮政编码，**全部按真实信息填，和信用卡账单地址保持一致**，地址信息可以写在一行内，其他地址栏可空着。内容可全部使用汉语拼音，但记得用空格分开，不要写成没有任何间隔的一整串字符。

7. **手机验证**：手机号不是最核心的验证项，填写自己国内的手机号码就可以了，但要确保这个号码之前未注册过甲骨文云。然后点继续

8. **信用卡验证**：

   接下来就到了注册最关键的一步，添加付款验证方式。

   点【**添加付款验证方式**】，然后点【**Credit Card**】按钮。这里会看到之前填写的用户信息，First Name是名，Last Name 是姓，地址信息，城市、邮编等等，都是之前用汉语拼音填写的，Oracle会自动将这些信息代入到这里，对照一下是否有错。

   支付信息这里，选择你手中的信用卡类型，通常中国用户开的卡要么是**VISA卡**，要么是**Mastercard卡**，选择你卡的对应类型，输入卡号，到期日期和安全码后。点击【**finish**】完成按钮，然后点【**Close**】按钮关闭窗口，返回之前【**添加付款验证方式**】页面。这时你的信用卡会被预扣款1.38新加坡元，这个是Oracle 的预授权验证，稍后会原路退回。

9. **确认协议并提交**：勾选服务协议，接下来就是见证奇迹的时刻，点击【**开始我的免费试用**】。当你看到这个蓝色的跑道时，恭喜你这个别大家喻为玄学的问题，已成功被你破解，现在你已经拿到了甲骨文云的账号，接下来就是等待甲骨文自己完成后续的初始化设置。如果看到的 A、B、C 错误提示说明这次注册失败了。也不要灰心，果断时间再试，不要频繁提交，会被标记。

提交后大概率会立刻看到结果（成功或失败），少数情况下会要求等待几分钟到几小时人工审核。

## 第三步：登录验证

**1、登录网址：**

[ 登录网址 ]：http://www.oracle.com/cn/cloud/free

**2、输入Oracle Cloud 账户名：**

这个名称就是创建时填写的【Cloud 账户名称】，必填，不是登录甲骨文云的用户和密码，填好后点下一步。

**3、Oracle Cloud 账户登录：**填写登录用户名及登录密码，就是申请甲骨文云时填写的邮箱和密码，然后点【登录】按钮。

**4、启用安全验证：**

这个是甲骨文云的安全验证机制，第一次登录时的必选项目，无法跳过。

点击【**启用安全验证**】之后。甲骨文云会要求我们手机上**下载Oracle的身份验证器，来绑定甲骨文云**。

这里我说明一下，默认情况下，这里要求下载的是Oracle自己的身份验证器，如果你没有其他验证器可用，按照提示下载安装这个验证器即可。由于网友说不知道注册时怎改成谷歌验证器，这里我就演示一下改成谷歌身份验证器，或其他验证器的方法。

如果时**海外手机**，无论是安卓手机还是苹果手机，都可在彼此的应用市场中，直接搜到 **Authenticator** 这个**谷歌验证器**，下载安装注册登录即可使用。如果是**国行手机**，能搜到的大概率是**微软的Authenticator身份验证器**。没关系一样能用，同样下载安装**微软的Authenticator身份验证器**并注册登录。

点击【**启用安全验证**】之后，在选择方法界面中，选择【移动应用程序】，然后勾选【**脱机模式或使用其他验证程序应用程序**】。

打开手机上安装的 **Authenticator身份验证器**，点击加号，然后用手机扫描下面的二维码，将账户添加到验证器中。然后将验证器中显示的验证码填写到步骤3的输入框中。然后点【**验证**】按钮，会看到 **已成功注册** 的提示，点【完成】按钮，登录甲骨文云后台。以后甲骨文登录验证时，就输入这个验证器中产生的码进行验证。

当然，如果你已经设置了甲骨文云自有验证器，想修改成谷歌验证器，也不用担心，去看看这个视频，详细说明了怎么**将Oracle身份验证器，变更成谷歌身份验证器**。

到这里，甲骨文云注册及登录步骤就全部完成了，现在你已经拥有了自己的甲骨文云账户。也不可避免的开启了自己的折腾之旅。

## 第四步：被拒之后怎么办

如果看到类似"处理交易时出错""无法完成您的注册"这类提示，**先别急着重复狂点提交**，大概率不会有用，反而可能因为短时间内多次尝试被判定为可疑行为。

按这个顺序调整：

1. **先自查一遍第一步的内容**——信息是否完全一致？卡是不是预付卡？是不是开着代理？系统环境是否调整到位？
2. **换一个变量再试**：比如换一个浏览器（有用户反馈 Chrome 失败、Firefox 成功，原因不明，但换着试成本很低）；或者换一个时间段重试
3. **给系统留点冷却时间**：不要在几分钟内反复提交，间隔几个小时甚至一两天再试，部分用户反馈短时间高频重试会让风控评分更差
4. **确认没有触发"重复账户"判定**：如果提示你似乎已经有账号，说明邮箱/手机/信用卡这三项里有一项之前用过，换一项重新尝试

> 心态上要接受一点：**有人准备得再充分，还是会失败几次。** 这不是你哪里做错了，这就是 Oracle 风控系统的真实运作方式。

## 常见报错与解决

| 报错现象 | 原因 | 解决步骤 |
|----------|------|----------|
| 处理交易时出错 / 无法完成您的注册 | 信息不完整或不一致、网络环境被判定可疑、或疑似重复注册 | 自查前期准备的内容，关闭VPN/代理，间隔一段时间后用不同变量重试 |
| 提示已存在使用其他邮箱的账户 | 手机号或信用卡之前注册过账号 | 换一个未使用过的手机号或信用卡重新尝试 |
| 信用卡验证失败 | 用了预付卡/虚拟卡，或卡的账单地址与填写信息不符 | 换成真实信用卡/借记卡，确认账单地址完全一致 |
| 注册成功但几天后账号被冻结 | 后续二次验证扣款失败（卡被注销或额度不足） | 保持注册用的卡处于正常可用状态，不要注销 |

## 注册成功后的两个提醒

1. **别注销注册用的那张卡**，前面提到过，Oracle 可能在后续做二次验证扣款，卡失效会导致账号冻结。
2. **别在短时间内频繁删机重建、跑高负载任务**，账号刚注册完风控敏感度更高，正常使用一段时间再放开手脚去抢 ARM 实例和折腾配置。
